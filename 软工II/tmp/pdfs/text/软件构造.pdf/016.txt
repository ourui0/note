大模型辅助调试与缺陷定位
大模型辅助错误信息分析
• 将编译错误、堆栈跟踪直接粘贴给大模型，快速定位根因和修复方
案
• 示例：将 NullPointerException 堆栈 + 相关代码输入大模型，获得精
准定位
大模型辅助缩小嫌疑代码范围
• 描述 Bug 现象，让大模型推断可能涉及的代码路径和数据流
• 结合 git diff，让大模型分析最近哪次修改最可能引入问题
大模型辅助修复与同类缺陷检测
• 获得修复建议后，追问：'代码库中还有哪些类似的写法可能存在同
样问题？'
• 利用大模型生成回归测试用例，防止同类缺陷复现

• "以下是我的 Java 代码和运行时异常堆栈，请定位缺陷原因并给出修
复方案，同时说明如何避免此类问题。"
