# 微观经济学

## **第一章：需求、供给和均衡价格 学习笔记**

### **一、 本章知识框架**

本章是微观经济学分析的基石，核心是**供求模型**。它揭示了市场中价格如何被决定以及如何调节资源配置。

1. **两大基本力量**：**需求**（消费者）与**供给**（生产者）。
2. **一个核心机制**：供求相互作用形成**市场均衡**，决定均衡价格和数量。
3. **一个重要工具**：**弹性**，用于量化供求对各因素反应的敏感程度。
4. **四大应用分析**：运用供求模型分析价格管制、税收、弹性与收益等现实问题。

### **二、 核心概念与知识点梳理**

**第一节 需 求**

1. **需求的概念**： 
   + **定义**：消费者在**一定时期**内，在**各种可能的价格水平**上**愿意而且能够**购买的商品数量。（包含“购买欲望”和“支付能力”两个要素） 
   + **表示方法**：需求表、需求曲线、需求函数（如 `Q^d = α - βP`）。 
   + **需求规律**：一般而言，**商品价格与其需求量呈反方向变动**。需求曲线向右下方倾斜。 
   + **特例**：吉芬商品（需求曲线向右上方倾斜）、完全无弹性（垂直线）、无限弹性（水平线）。
2. **影响需求的因素（导致需求曲线移动）**： 消费者收入 消费者偏好 相关商品价格（替代品、互补品） 消费者预期 政府政策
3. **需求量的变动 vs. 需求的变动**： 
   + **需求量的变动**：由商品**自身价格**变动引起，表现为**沿同一条需求曲线**的移动。 
   + **需求的变动**：由**价格以外**的其他因素变动引起，表现为**需求曲线本身的平移**。

**第二节 供 给**

1. **供给的概念**： 
   + **定义**：生产者在**一定时期**内，在**各种可能的价格水平**上**愿意而且能够**出售的商品数量。（包含“出售意愿”和“供给能力”两个要素） 
   + **表示方法**：供给表、供给曲线、供给函数（如 `Q^s = γ + δP`）。 
   + **供给规律**：一般而言，**商品价格与其供给量呈同方向变动**。供给曲线向右上方倾斜。
2. **影响供给的因素（导致供给曲线移动）**： 生产技术水平 生产成本（投入品价格） 生产者目标 相关商品价格 生产者预期 政府政策
3. **供给量的变动 vs. 供给的变动**：区分原理同需求，自身价格变动导致“**线上点**”移动，其他因素导致“**线本身**”移动。

**第三节 市场均衡**

1. **均衡**：供求力量达到平衡，相对静止的状态。在均衡点 `Q^d = Q^s`。
2. **均衡价格与均衡数量**：市场出清时的价格和交易量。
3. **均衡的变动（供求分析三步法）**：任何导致**需求或供给曲线移动**的因素都会改变均衡。 **需求增加** → 均衡价格**上升**，均衡数量**增加**。 **供给增加** → 均衡价格**下降**，均衡数量**增加**。 （结合PPT中的表格，可分析各种组合情况）

**第四节 弹 性**

1. **概念**：衡量一个变量对另一个变量变化反应的**敏感程度**（百分比变化之比），无量纲。
2. **需求的价格弹性**： 
   + **公式**：`Ed = (ΔQ/Q) / (ΔP/P)`。 
   + **类型**：完全无弹性、缺乏弹性、单位弹性、富有弹性、无限弹性。 
   + **影响因素**：商品可替代性、重要程度、支出占比、调整时间。
   +  **与销售收入的关系**（核心结论）： `Ed > 1`（富有弹性）：降价能**增加**总收益（薄利多销）。 `Ed < 1`（缺乏弹性）：降价会**减少**总收益（谷贱伤农）。 `Ed = 1`：价格变动不影响总收益。
3. **其他弹性**： 
   + **需求的收入弹性**：区分正常品（`Em > 0`）和低档品（`Em < 0`），正常品中又可分必需品（`0<Em<1`）和奢侈品（`Em>1`）。 
   + **需求的交叉价格弹性**：`Ec > 0`为替代品；`Ec < 0`为互补品。

**第五节 供求分析的应用**

1. **价格管制**： **支持价格（最低限价）**：高于均衡价，导致**供给过剩**。 **限制价格（最高限价）**：低于均衡价，导致**供给短缺**。
2. **税收效应分析**： 税收（无论向买方还是卖方征收）都会**提高买方支付的价格，降低卖方得到的价格**，并**减少交易量**。 **税收归宿**（税负实际由谁承担）取决于**供求弹性**：弹性小的一方承担更多税负。（见PPT案例）
3. **弹性与收入**：即上述“需求价格弹性与总收益”的关系，是分析“谷贱伤农”等现象的理论基础。

### **三、 知识应用：结合第一章作业题深化理解**

以下将作业题目作为案例，融入对应知识点，展示理论如何应用。

| 作业题                            | 对应的核心知识点                                             | 分析与解题关键                                               |
| --------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **第1题**：求均衡、弹性及税收分担 | **第三节：市场均衡**  **第四节：弹性**  **第五节：税收效应** | 1. **求均衡**：联立 `Qd=Qs`解方程。 2. **求弹性**：在均衡点处，利用导数或公式计算点弹性。 3. **税收分担**：税收造成供求曲线相对移动，形成新的均衡。**消费者负担** = 新均衡价 - 原均衡价；**生产者负担** = 税收 - 消费者负担。税收分担比例取决于供求弹性。 |
| **第2题**：利用弹性进行预测       | **第四节：弹性（收入弹性、价格弹性）**                       | 1. **公式应用**：`ΔQ/Q ≈ 收入弹性 * Δm/m + 价格弹性 * ΔP/P`（此处为近似计算，假设其他条件不变）。 2. **综合计算**：将收入变动和价格变动对需求量的影响百分比相加，再乘以基期销售量，即可估算新的销售量。这正是弹性的预测功能。 |
| **第3题**：分析新能源汽车价格波动 | **第一、二、三节综合**：需求/供给的影响因素及均衡变动        | 1. **分析框架**：采用“**三步法**”。 - **第一步**：判断事件影响**需求**还是**供给**，或两者都影响。 - **第二步**：判断曲线移动**方向**。 - **第三步**：图示分析对均衡价格和数量的**影响**。 2. **结合现实**： - **需求侧**：政策补贴（增加需求）、技术进步提升体验（增加需求）、消费者偏好变化（增加需求）。 - **供给侧**：技术进步降成本（增加供给）、原材料（如锂）价格波动（影响供给成本）。 - **综合**：不同时期，主导因素不同，导致价格波动。 |
| **第4题**：解释“谷贱伤农”         | **第四节：需求价格弹性与收益**                               | 1. **核心原因**：**粮食的需求缺乏价格弹性**（`Ed < 1`）。 2. **解释**：丰收→供给大增→粮价大幅下跌。由于需求缺乏弹性，价格下跌的百分比**大于**需求量增加的百分比，导致农民总收益（P×Q）**下降**。反之，歉收时供给减少，粮价上涨幅度大，总收入可能增加。这完全是**需求弹性特性**导致的结果。 |

### **四、 易错点与难点总结（来自作业与PPT提示）**

1. **“需求/供给的变动” vs “需求量/供给量的变动”**：这是核心基础，务必通过图形清晰区分。作业第3题的分析前提就是正确判断曲线如何移动。
2. **均衡变动的分析**：务必遵循“**三步法**”，先确定哪条线动、向哪动，再看新均衡点。PPT中供求同时变动的表格结论，也建议通过此方法自行推导，而非死记。
3. **弹性的计算与含义**：弹性是**百分比之比**，不是斜率。点弹性和弧弹性适用场景不同。**需求价格弹性与总收益的关系**是高频考点（对应作业2、4题）。
4. **税收归宿的理解**：税收的法定归宿（向谁征税）与经济归宿（实际由谁承担）不同。实际承担比例由**供求弹性决定**，弹性小的一方更“被动”，承担更多税负（见PPT案例分析）。
