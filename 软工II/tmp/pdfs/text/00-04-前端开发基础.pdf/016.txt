JavaScript — 动态⾏为层
让⻚⾯"活"起来：响应⽤户操作、异步更新数据
// 1. 操作  DOM ：响应点击事件
document.getElementById('btn').addEventListener('click', () => {
  document.getElementById('msg').textContent = ' 你点击了按钮！ ';
});
// 2. 异步请求（ AJAX / Fetch API ）：不刷新⻚⾯获取数据
fetch('/api/data')
  .then(res => res.json())
  .then(data => {
    console.log(data);
    // ⽤数据更新⻚⾯  DOM
  });
JavaScript 只负责交互⾏为和数据通信，不负责内容结构和外观样式。
