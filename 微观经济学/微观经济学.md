# 微观经济学

## **第一章：需求、供给和均衡价格 学习笔记**

### **一、 本章知识框架**

本章是微观经济学分析的基石，核心是**供求模型**。它揭示了市场中价格如何被决定以及如何调节资源配置。

1. **两大基本力量**：**需求**（消费者）与**供给**（生产者）。
2. **一个核心机制**：供求相互作用形成**市场均衡**，决定均衡价格和数量。
3. **一个重要工具**：**弹性**，用于量化供求对各因素反应的敏感程度。
4. **四大应用分析**：运用供求模型分析价格管制、税收、弹性与收益等现实问题。

### **二、 核心概念与知识点梳理**

**第一节 需 求**

1. **需求的概念**： 
   + **定义**：消费者在**一定时期**内，在**各种可能的价格水平**上**愿意而且能够**购买的商品数量。（包含“购买欲望”和“支付能力”两个要素） 
   + **表示方法**：需求表、需求曲线、需求函数（如 `Q^d = α - βP`）。 
   + **需求规律**：一般而言，**商品价格与其需求量呈反方向变动**。需求曲线向右下方倾斜。 
   + **特例**：吉芬商品（需求曲线向右上方倾斜）、完全无弹性（垂直线）、无限弹性（水平线）。
2. **影响需求的因素（导致需求曲线移动）**： 消费者收入 消费者偏好 相关商品价格（替代品、互补品） 消费者预期 政府政策
3. **需求量的变动 vs. 需求的变动**： 
   + **需求量的变动**：由商品**自身价格**变动引起，表现为**沿同一条需求曲线**的移动。 
   + **需求的变动**：由**价格以外**的其他因素变动引起，表现为**需求曲线本身的平移**。

**第二节 供 给**

1. **供给的概念**： 
   + **定义**：生产者在**一定时期**内，在**各种可能的价格水平**上**愿意而且能够**出售的商品数量。（包含“出售意愿”和“供给能力”两个要素） 
   + **表示方法**：供给表、供给曲线、供给函数（如 `Q^s = γ + δP`）。 
   + **供给规律**：一般而言，**商品价格与其供给量呈同方向变动**。供给曲线向右上方倾斜。
2. **影响供给的因素（导致供给曲线移动）**： 生产技术水平 生产成本（投入品价格） 生产者目标 相关商品价格 生产者预期 政府政策
3. **供给量的变动 vs. 供给的变动**：区分原理同需求，自身价格变动导致“**线上点**”移动，其他因素导致“**线本身**”移动。

**第三节 市场均衡**

1. **均衡**：供求力量达到平衡，相对静止的状态。在均衡点 `Q^d = Q^s`。
2. **均衡价格与均衡数量**：市场出清时的价格和交易量。
3. **均衡的变动（供求分析三步法）**：任何导致**需求或供给曲线移动**的因素都会改变均衡。 **需求增加** → 均衡价格**上升**，均衡数量**增加**。 **供给增加** → 均衡价格**下降**，均衡数量**增加**。 （结合PPT中的表格，可分析各种组合情况）

**第四节 弹 性**

1. **概念**：衡量一个变量对另一个变量变化反应的**敏感程度**（百分比变化之比），无量纲。
2. **需求的价格弹性**： 
   + **公式**：`Ed = (ΔQ/Q) / (ΔP/P)`。 
   + **类型**：完全无弹性、缺乏弹性、单位弹性、富有弹性、无限弹性。 
   + **影响因素**：商品可替代性、重要程度、支出占比、调整时间。
   +  **与销售收入的关系**（核心结论）： `Ed > 1`（富有弹性）：降价能**增加**总收益（薄利多销）。 `Ed < 1`（缺乏弹性）：降价会**减少**总收益（谷贱伤农）。 `Ed = 1`：价格变动不影响总收益。
3. **其他弹性**： 
   + **需求的收入弹性**：区分正常品（`Em > 0`）和低档品（`Em < 0`），正常品中又可分必需品（`0<Em<1`）和奢侈品（`Em>1`）。 
   + **需求的交叉价格弹性**：`Ec > 0`为替代品；`Ec < 0`为互补品。

**第五节 供求分析的应用**

1. **价格管制**： **支持价格（最低限价）**：高于均衡价，导致**供给过剩**。 **限制价格（最高限价）**：低于均衡价，导致**供给短缺**。
2. **税收效应分析**： 税收（无论向买方还是卖方征收）都会**提高买方支付的价格，降低卖方得到的价格**，并**减少交易量**。 **税收归宿**（税负实际由谁承担）取决于**供求弹性**：弹性小的一方承担更多税负。（见PPT案例）
3. **弹性与收入**：即上述“需求价格弹性与总收益”的关系，是分析“谷贱伤农”等现象的理论基础。

### **三、 知识应用：结合第一章作业题深化理解**

### **四、 易错点与难点总结（来自作业与PPT提示）**

1. **“需求/供给的变动” vs “需求量/供给量的变动”**：这是核心基础，务必通过图形清晰区分。作业第3题的分析前提就是正确判断曲线如何移动。
2. **均衡变动的分析**：务必遵循“**三步法**”，先确定哪条线动、向哪动，再看新均衡点。PPT中供求同时变动的表格结论，也建议通过此方法自行推导，而非死记。
3. **弹性的计算与含义**：弹性是**百分比之比**，不是斜率。点弹性和弧弹性适用场景不同。**需求价格弹性与总收益的关系**是高频考点（对应作业2、4题）。
4. **税收归宿的理解**：税收的法定归宿（向谁征税）与经济归宿（实际由谁承担）不同。实际承担比例由**供求弹性决定**，弹性小的一方更“被动”，承担更多税负（见PPT案例分析）。

## **第二章 消费者选择 相关知识点**

本章核心是研究消费者如何在有限收入下做出最优消费决策，以实现满足感（效用）最大化。作业第1、2题涉及本章内容。

### **一、 效用与偏好**

1. **效用**：消费者从商品消费中获得的满足感，是主观评价。
2. **偏好**：消费者对商品组合的喜好排序。经济学对偏好有四个基本假设：可排序性、传递性、多比少好、偏好多样性。
3. **效用函数**：表示偏好或效用水平的数学函数形式。作业中出现了两种形式： **完全互补型**：`u(x, y) = min{ x, y/3 }`。表示两种商品必须按固定比例（本例为1:3）消费才能产生效用，单独超量消费无效。其**无差异曲线呈直角形**。 **柯布-道格拉斯型等**：如 `U = Qx^(3/2) * Qy`。表示消费者喜欢消费的多样性，其**无差异曲线凸向原点**。

### **二、 消费者均衡（效用最大化条件）**

消费者在**预算约束线**与**无差异曲线**的切点处实现均衡，此时满足以下条件：

1. **图形条件**：预算约束线的斜率 = 无差异曲线的斜率（绝对值）。
2. **公式条件**： **一般形式**：`MRS₁,₂ = P₁ / P₂`。其中，`MRS₁,₂`（边际替代率）表示两种商品在效用不变时的替代比率。 **与基数效用的联系**：`MRS₁,₂ = MU₁ / MU₂`。因此，均衡条件可写为 **`MU₁ / P₁ = MU₂ / P₂ = λ`**（λ为货币的边际效用）。此条件可推广到多种商品。 **对于完全互补偏好**：均衡点位于无差异曲线的“拐点”上，满足固定消费比例关系（如 `x = y/3`），**而不是**在切点处满足 `MRS = P1/P2`。

### **三、 需求曲线的推导**

消费者在每一价格下根据效用最大化原则确定的需求量，连起来就构成了个人需求曲线。在边际效用递减规律作用下，**需求曲线向右下方倾斜**。

**对应作业题目**：

- **第1题**：考察**完全互补偏好**下的消费者行为。其消费组合由固定比例 (`x = y/3`) 决定，只要比例不变，相对价格变动**不会改变**消费组合。需求函数需结合此比例与预算约束 `Px*x + Py*y = I`联合求解。
- **第2题**：考察**不同效用函数**下的消费者均衡求解及偏好理解。 第(1)问：对小明（C-D效用函数）和小红（复杂函数），均需运用均衡条件 **`MU_x / P_x = MU_y / P_y`** 结合预算约束联立求解。 第(2)问：即使两人最优购买量相同，**也不违背“无差异曲线不相交”的假设**。因为该假设是针对**同一个**消费者的偏好而言的。不同消费者的偏好（效用函数）不同，他们的无差异曲线族是不同的，在价格和收入给定时，完全可能选择相同的消费束，但这只是两条**分属不同无差异曲线族**的曲线恰好在某点数值相等，并非“相交”。

## **第三章 企业的生产和成本 相关知识点**

本章核心是研究企业生产的技术约束（投入与产出的关系）和经济约束（成本），为理解企业利润最大化打下基础。作业第3、4题涉及本章内容。

### **一、 生产函数（投入与产出的技术关系）**

1. **短期与长期**：短期至少有一种要素（如资本K）固定不变；长期所有要素都可变。
2. **短期生产函数**：`Q = f(L, K̅)`，重点分析一种可变要素（劳动L）。
3. **核心概念**： **总产量 (TP/L)**：一定投入所能生产的最大产量。 **平均产量 (AP/L)**：`APL = TP/L / L`。 **边际产量 (MP/L)**：`MPL = ΔTP/L / ΔL = d(TP/L) / dL`。**边际报酬递减规律**：在技术和其他投入不变时，持续增加一种可变投入，其边际产量最终会递减。
4. **三阶段与合理投入区间**： **第Ⅰ阶段**：`AP`递增，`MP > AP`。可变投入不足，固定要素未充分利用。 **第Ⅱ阶段**：`AP`递减，`MP > 0`。**短期生产的合理区间**。 **第Ⅲ阶段**：`MP < 0`。可变投入过多，总产量下降。

**对应作业第3题**：

- 第(1)问：直接根据定义，对总产量函数 `Q=35L+8L²-L³`求导得 `MPL`，除以 `L`得 `APL`。
- 第(2)问：判断 `L=6`是否在**第Ⅱ阶段**。需计算 `MPL`在 `L=6`时是否大于0，同时 `APL`是否已处于递减阶段（即 `MPL < APL`）。

### **二、 成本函数**

1. **短期成本概念**（至关重要）： **总成本 (TC)** = **固定成本 (FC)** + **可变成本 (VC)**。 **平均成本 (AC)** = `TC/Q`= **平均固定成本 (AFC)** + **平均可变成本 (AVC)**。 **边际成本 (MC)** = `ΔTC/ΔQ`= `ΔVC/ΔQ`= `d(TC)/dQ`。
2. **各类短期成本曲线的形状与关系**： `MC`、`AVC`、`AC`曲线均呈 **“U”形**。 **`MC`曲线依次穿过 `AVC`曲线和 `AC`曲线的最低点**。 当 `MPL`递增时，`MC`递减；当 `MPL`递减时，`MC`递增。数学关系为：`MC = w / MPL`（w为工资率）。
3. **从边际成本推导总成本**：短期总成本函数 `STC(Q)`是边际成本函数 `MC(Q)`的积分。积分会产生一个常数，即**固定成本 `FC`**，其值需借助题目给定的条件（如“当Q=5时，STC=200”）来确定。

**对应作业第4题**：

- 第(1)问：已知 `MC(Q)=3Q²-20Q+57`，对其积分得 `VC(Q) = ∫MC dQ = Q³ - 10Q² + 57Q + C`。常数`C`通过条件`STC(5)=200`求出，并分解出`FC`。再根据定义求出 `AC`、`AVC`、`AFC`。
- 第(2)问：最小的平均可变成本出现在 `AVC`曲线最低点，该点满足 **`MC = AVC`**。求解此方程得到的Q值代入 `AVC(Q)`函数，即可得最小可变平均成本。
