前沿：多 Agent 辩论（M AD）分类需求 [RE 2025]
 
原理：让多个 AI 互相辩论，提⾼需求分类准确率
⻆⾊ 职责
倡导者 Agent 为某个分类结果辩护，提供论据
批评者 Agent 质疑分类结果，指出漏洞
裁判 Agent 综合双⽅论据，做出最终判定
 
实验效果（RE 2025 论⽂）
⽅法 F1 分数
单 Agent 直接分类 0.726
多 Agent 辩论（MAD） 0.841（+15.8%）
 这与需求评审中的同级评审理念⼀致——多个视⻆⽐单⼀视⻆更可靠。
