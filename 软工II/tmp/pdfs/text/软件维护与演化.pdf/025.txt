大模型辅助软件维护活动
四类维护中 AI 的介入方式
纠错性维护：AI 分析 Bug 报告 + 代码，定位根因，生成修复方案
适应性维护：AI 分析变更影响范围，生成适配新环境的修改方案
完善性维护：AI 识别性能瓶颈，提供优化建议并生成重构代码
预防性维护：AI 识别技术债务，制定优先级清单，逐步偿还
变更请求处理中的 AI 辅助
变更分析：「此需求变更影响哪些模块？估算工作量？存在哪些风险 ？」
影响域识别：AI 构建变更影响图，自动标记需要回归测试的范围
Claude Code 纠错性维护示例
$ claude "生产环境报告：用户导出 Excel 时文件损坏（Issue #4521）。
分析 src/export/ 目录，定位根因，生成修复 patch 并补充回归测试"
AI 自主：读取错误日志 → 定位代码 → 生成修复 → 验证测试 → 提交 PR
维护知识的持续积累
每次维护活动后，AI 自动生成「维护案例卡片 」：问题描述、根因、解决方案
积累的案例库成为 RAG 知识库，加速后续类似问题的处理
