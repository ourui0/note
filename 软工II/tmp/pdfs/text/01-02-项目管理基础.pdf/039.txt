Git 三⼤分区与核⼼操作
开发者本地
  ┌──────────────────────┐  git add  ┌──────────────────┐
  │  ⼯作区                 │ ────────  │  暂存区（ Index ）    │
  │  (Working Directory) │           └──────────────────┘
  └──────────────────────┘                    │ git commit
                                              ▼
                                     ┌──────────────────┐
                                     │  版本库（ Repo ）     │
                                     └──────────────────┘
                                              │ git push
                                              ▼
                                     ┌──────────────────┐
                                     │  远程仓库（ Remote ） │
                                     └──────────────────┘
命令 ⽐较对象 ⽤途
git diff ⼯作区 vs 暂存区 查看未 add 的修改
git diff HEAD ⼯作区 vs 最新提交 查看所有未提交的修改
git diff --cached 暂存区 vs 最新提交 查看已 add 但未 commit 的修改 39
