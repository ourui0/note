# 第02章 关系代数考前复习

参考：第02章关系代数讲义、复习思考题、数据管理基础期末练习（2026）。

## 一、样卷考法

2026 样卷关系代数大题使用产品销售数据库：

```text
顾客 C(cid, cname, city, dis)
供应商 A(aid, aname, city, per)
商品 P(pid, pname, qua, price)
订单 O(ordno, orddate, cid, aid, pid, qty, dols)
```

其中：

```text
cid, aid, pid, ordno 分别是 C, A, P, O 的码
```

高频题型：

- 选择 + 投影 + 连接。
- 差运算表示“没有……”。
- 自连接表示“最高 / 最大 / 最后”。
- 除法表示“所有……”。
- 关系重命名，避免同名属性混淆。
- 自己城市中的所有顾客这类“分组式所有”。

## 二、关系代数基本运算

关系代数是一种抽象查询语言：

- 运算对象是关系。
- 运算结果也是关系。
- 关系操作是集合操作。

五种基本运算：

| 运算 | 符号 | 含义 |
| --- | --- | --- |
| 并 | `R ∪ S` | 属于 R 或 S 的元组 |
| 差 | `R - S` | 属于 R 但不属于 S 的元组 |
| 笛卡尔积 | `R × S` | R 与 S 的元组两两组合 |
| 选择 | `σ条件(R)` | 按行筛选 |
| 投影 | `π属性列表(R)` | 按列筛选，自动去重 |

扩充运算：

- 交：`R ∩ S`
- 连接：`R ⋈ S`
- θ 连接：`R ⋈条件 S`
- 自然连接：`R ⋈ S`
- 除：`R ÷ S`
- 外连接

样卷选择题：**交运算不是基本关系操作**。基本操作是：

```text
并、差、笛卡尔积、选择、投影
```

## 三、相容关系

并、差、交要求两个关系相容。

相容条件：

- 属性个数相同。
- 对应属性的域相同。

例：

```text
πcid(C) - πcid(O)
```

合法，因为两边都是单属性关系，且属性都是顾客编号。

不合法例子：

```text
C - O
```

因为 C 和 O 属性个数、含义不同。

## 四、选择与投影

选择 `σ`：筛选元组。

```text
σcity='南京'(C)
```

表示南京市顾客。

投影 `π`：选取属性列。

```text
πcid,cname(C)
```

表示查询顾客编号和姓名。

组合例题：

查询南京市顾客的编号和姓名：

```text
πcid,cname(σcity='南京'(C))
```

注意：

- 先选择再投影通常更自然。
- 投影结果会自动去重。

## 五、连接

连接用于把多个关系按条件组合。

常用写法：

```text
C ⋈ O
```

如果两个关系有同名属性 `cid`，自然连接会自动按同名属性相等连接。

更明确的写法：

```text
σC.cid=O.cid(C × O)
```

或：

```text
C ⋈C.cid=O.cid O
```

## 六、例题1：选择 + 连接

题目：查询位于“苏州”市且通过“南京”市供应商购买过商品的顾客编号和姓名。

关系路径：

```text
顾客 C -> 订单 O -> 供应商 A
```

表达式：

```text
πcid,cname(
  (σcity='苏州'(C) ⋈ O)
  ⋈
  πaid(σcity='南京'(A))
)
```

也可写得更完整：

```text
πC.cid,C.cname(
  σC.city='苏州' ∧ A.city='南京' ∧ C.cid=O.cid ∧ O.aid=A.aid
  (C × O × A)
)
```

考试建议：

- 如果自然连接会出现多个同名属性，最好加关系名前缀，如 `C.city`、`A.city`。
- `city` 在 C 和 A 中都有，必须区分顾客城市和供应商城市。

## 七、例题2：不同城市连接

题目：查询订单编号、顾客所在城市和供应商所在城市，要求订单上的顾客和供应商不在同一城市。

表达式：

```text
πO.ordno,C.city,A.city(
  σC.city<>A.city(C × A) ⋈ O
)
```

更完整：

```text
πO.ordno,C.city,A.city(
  σC.cid=O.cid ∧ A.aid=O.aid ∧ C.city<>A.city
  (C × O × A)
)
```

注意：

- `C.city` 和 `A.city` 是两个不同属性，输出时可理解为顾客城市、供应商城市。

## 八、差运算：“没有……”

“没有购买过商品”的顾客：

```text
πcid(C) - πcid(O)
```

如果还要姓名：

```text
πcname(
  (πcid(σcity='南京'(C)) - πcid(O))
  ⋈ C
)
```

例题：查询位于南京市且没有购买过商品的顾客姓名。

```text
πcname(
  (πcid(σcity='南京'(C)) - πcid(O))
  ⋈ C
)
```

思路：

1. 先找南京顾客编号。
2. 减去有订单的顾客编号。
3. 再连接 C 取姓名。

模板：

```text
目标对象 - 已经做过某事的对象
```

## 九、重命名

自连接时必须重命名，否则无法区分同一个关系的两份拷贝。

记号：

```text
M := O
N := O
```

或：

```text
ρM(O), ρN(O)
```

用途：

- 比较同一供应商的不同订单。
- 查找最大值 / 最小值。
- 查找最后一份订单。

## 十、例题3：每组最大值

题目：在每一个供应商自己的所有订单中，查询销售金额 `dols` 最高的订单，返回供应商编号、订单编号和销售金额。

思路：

- 所有订单集合。
- 减去“存在同一供应商的另一张订单销售金额更高”的订单。
- 剩下的就是每个供应商最高销售金额订单。

令：

```text
M := O
N := O
```

表达式：

```text
πaid,ordno,dols(O)
-
πM.aid,M.ordno,M.dols(
  σM.aid=N.aid ∧ M.dols<N.dols(M × N)
)
```

说明：

- `M.dols < N.dols` 表示 M 不是最高，因为同供应商存在更高的 N。
- 如果有并列最高，都会保留。

模板：

```text
R - 存在同组更大的 R
```

查最小值则改成：

```text
R - 存在同组更小的 R
```

## 十一、除法：“所有……”

除法适合表达“对所有对象都满足”。

直观含义：

```text
R(X, Y) ÷ S(Y)
```

得到那些 `X`，使得对 `S` 中每个 `Y`，`(X,Y)` 都在 `R` 中。

通俗：

```text
谁 覆盖了 所有目标
```

例：

```text
供应商-销售城市(aid, city) ÷ 顾客城市(city)
```

得到在所有有顾客的城市中都销售过商品的供应商。

## 十二、例题4：所有有顾客的城市

题目：查询在所有有顾客的城市中都销售过商品的供应商编号。

先构造：

```text
供应商销售到的顾客城市：
πO.aid,C.city(O ⋈ C)
```

所有有顾客的城市：

```text
πcity(C)
```

表达式：

```text
πO.aid,C.city(O ⋈ C) ÷ πcity(C)
```

解释：

- 被除关系属性是 `(aid, city)`。
- 除关系属性是 `(city)`。
- 结果属性是 `(aid)`。

注意：

- 除法右边属性必须是左边属性的一部分。
- 左边必须准备好“供应商 aid 与顾客城市 city”的对应关系。

## 十三、例题5：向自己城市所有顾客销售

题目：查询向供应商自己所在城市中的所有顾客都销售过商品的供应商编号。

这是“每个供应商对应一个不同的目标集合”的所有问题。

参考思路：

1. 候选供应商集合。
2. 找出“应该销售”的 `(cid, aid)`：顾客城市 = 供应商城市。
3. 找出实际销售过的 `(cid, aid)`。
4. 应该销售但没有销售的供应商是不合格供应商。
5. 候选供应商减去不合格供应商。

表达式：

```text
πaid(O)
-
πaid(
  πcid,aid(C ⋈ A)
  -
  πcid,aid(O)
)
```

更明确写法：

```text
πaid(O)
-
πaid(
  πC.cid,A.aid(σC.city=A.city(C × A))
  -
  πcid,aid(O)
)
```

说明：

- `πC.cid,A.aid(σC.city=A.city(C × A))` 表示每个供应商对自己城市顾客“应该销售”的组合。
- `πcid,aid(O)` 表示实际销售过的顾客-供应商组合。
- 两者相减得到“缺失销售”的组合。
- 对缺失组合投影 aid 得到不合格供应商。
- 从候选供应商中减去不合格供应商。

边界提醒：

- 使用 `πaid(O)` 表示只考虑有订单的供应商。
- 如果严格考虑“供应商所在城市没有顾客”的空集真问题，可用 `πaid(A)` 作为候选集合。但样卷参考答案用 `πaid(O)`，考试按参考答案掌握即可。

## 十四、交运算

交可以由差推出：

```text
R ∩ S = R - (R - S)
```

例：

既是南京顾客又买过商品的顾客编号：

```text
πcid(σcity='南京'(C)) ∩ πcid(O)
```

也可写为：

```text
πcid(σcity='南京'(C))
-
(
  πcid(σcity='南京'(C)) - πcid(O)
)
```

## 十五、连接与自然连接易错点

自然连接会自动按同名属性相等连接，并去掉重复列。

优点：

- 表达简洁。

风险：

- 如果两个关系有同名但语义不同的属性，会错误连接。

例如：

```text
C(city) 和 A(city)
```

顾客城市和供应商城市都叫 `city`，如果直接 `C ⋈ A`，自然连接会默认要求 `C.city = A.city`。

有时这是题目需要的，例如自己城市顾客；有时不是，需要改用笛卡尔积加条件。

考试建议：

- 涉及多个 `city` 时，写成 `C.city`、`A.city`。
- 不确定自然连接是否安全时，用 `σ条件(C × A × O)` 明确写出连接条件。

## 十六、关系代数与 SQL 对应

| 关系代数 | SQL |
| --- | --- |
| `σ条件(R)` | `where 条件` |
| `π属性(R)` | `select 属性` |
| `R × S` | `from R, S` 无连接条件 |
| `R ⋈ S` | `join` 或 `where R.a=S.a` |
| `R - S` | `except` / `not exists` |
| `R ÷ S` | 双重 `not exists` |
| 自连接 | 同一表起两个别名 |

## 十七、样卷 6 类模板汇总

### 1. 条件连接

```text
π目标属性(σ条件(R × S × T))
```

### 2. 没有做过

```text
π目标(候选集合 - 已做集合)
```

### 3. 每组最大

```text
R - 存在同组更大的 R
```

具体：

```text
π组,编号,值(R)
-
πM.组,M.编号,M.值(
  σM.组=N.组 ∧ M.值<N.值(M × N)
)
```

### 4. 所有

```text
R(X,Y) ÷ S(Y)
```

### 5. 自己所在城市所有顾客

```text
候选供应商
-
πaid(应该销售(cid,aid) - 实际销售(cid,aid))
```

### 6. 只通过某供应商 / 只满足某条件

“只……”通常用：

```text
做过集合 - 做过违反条件的集合
```

例：只通过 a001 供应商购买过商品的顾客编号。

```text
πcid(σaid='a001'(O))
-
πcid(σaid<>'a001'(O))
```

如果要求“购买过商品，且仅通过 a001”，上式正合适。

## 十八、考前检查清单

写关系代数时检查：

1. 输出属性是不是题目要求的？
2. 同名属性有没有加关系名前缀？
3. 差、并、交两边是否相容？
4. 自连接是否重命名？
5. “没有”是否用差？
6. “所有”是否用除法？
7. “最大/最高/最后”是否用自连接排除非最大？
8. 自然连接是否会误用同名属性？
9. 投影是否过早导致后续连接属性丢失？
10. 除法左边是否包含右边属性？
