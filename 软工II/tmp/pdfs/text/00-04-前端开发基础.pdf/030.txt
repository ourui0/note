Node.js — JavaScript 的后端⼒量
Node.js = V8 引擎 + 事件循环 + ⾮阻塞 I/O
传统服务器（多线程模型）：
  请求 1 ──► 线程 1 [ 等待数据库 ] ──────────► 响应 1
  请求 2 ──► 线程 2 [ 等待⽂件 IO] ──────────► 响应 2
  请求 3 ──► 线程 3 [ 等待 ...]    ──────────► 响应 3
  （线程池耗尽  → 新请求排队等待）
Node.js （事件驱动  + ⾮阻塞）：
  请求 1 ──► 发起 IO → [ 继续处理其他请求 ]
  请求 2 ──► 发起 IO → [ 继续处理其他请求 ]
  请求 3 ──► 发起 IO → [ 继续处理其他请求 ]
  IO 完成  ──► 回调函数处理结果  ──► 响应
  （单线程  + 事件队列，⾼并发不阻塞）
核⼼优势：
特性 说明
⾼并发 事件驱动，单线程处理⼤量并发连接
前后同语⾔全栈均⽤ JavaScript，降低切换成本
