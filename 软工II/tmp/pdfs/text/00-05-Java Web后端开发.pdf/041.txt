课堂总结：三层技术栈 = 三道防线
Browser / Postman / 移动  App
            │
            ▼
┌───────────────────────────────────────────┐
│   Spring Security  过滤器链                │
│   JWT 验证  · 认证鉴权  · 拦截未授权请求     │  ← 第⼀道：守⻔员
└──────────────────┬────────────────────────┘
                   │
┌──────────────────▼────────────────────────┐
│   Spring Boot   Controller + Service       │
│   RESTful API · 业务逻辑  · 参数校验         │  ← 第⼆道：业务处理
└──────────────────┬────────────────────────┘
                   │
┌──────────────────▼────────────────────────┐
│   MyBatis   Mapper + MySQL                 │
│   参数化查询  · 防  SQL 注⼊  · 最⼩权限账号   │  ← 第三道：数据守护
└───────────────────────────────────────────┘
