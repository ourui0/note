三层架构的分⼯协作
┌──────────────────────────────────────────────┐
│            ⼀个⽹⻚  = 三层叠加                │
│                                              │
│  HTML  ──  ⻣架（内容、结构、语义）            │
│  CSS   ──  ⽪肤（颜⾊、字体、布局、动画）      │
│  JS    ──  肌⾁（交互、数据、动态更新）        │
└──────────────────────────────────────────────┘
类⽐：
HTM L  是⼀栋楼的钢筋混凝⼟结构
CSS 是室内装修（颜⾊、灯光、家具）
JavaScript 是电梯和⾃动⻔（响应⼈的操作）
三层分离的好处：
结构清晰，各司其职，便于团队协作
CSS 换⽪不影响内容；JS 逻辑不污染 HTM L
浏览器可独⽴缓存各层资源，提升性能
