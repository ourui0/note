软件建⽴的依据
单纯的软件系统不能解决问题，它只有和现实世界形成有效互动才能实现问题的解决
 
  问题 ( 现实世界 )                                                     改进 ( 现实世界 )
       │                                                                ▲
       ▼ 抽象                                                           │ 应⽤
  ┌──────────────┐    建模      ┌──────────────┐    实现     ┌──────────────┐
  │ 现实知识 + 问题   │ ────────→ │ 软件构建⽅案     │ ───────→ │   应⽤程序      │
  └──────────────┘           └──────────────┘          └──────────────┘
 
 软件开发的起点不是代码，⽽是对现实世界问题的理解。
