# 实验三实现记录

## 需求

依据《实验三——中间代码生成》和《实验三指导》，实现整数 C-- 的线性三地址代码生成。唯一选做为 3.2：一维数组引用传参及局部多维数组。结构体 3.1 不实现，给出手册规定的拒绝提示。

## 结构

- parser.c / parser.y / lexer.l / parser.h：沿用实验二语法树；增加两文件参数接口和关系操作符文本保留。
- semantic.c / semantic.h：沿用语义检查；预定义 read、write，并返回检查是否成功。
- ir.c / ir.h：单独进行生成；指令先保存链表，再做紧邻跳转消除和统一输出。
- 数组 Shape 记录递归元素形状/宽度；数组参数保存引用，局部数组 DEC 分配。
- 表达式保存值与地址的区别；标量读取使用临时量，避免后续副作用改变已求值结果。
- 参数先求值后逆序 ARG，逻辑表达式按真假标号短路。
- 基础优化包括安全整数常量折叠、立即数、加减零/乘一、跳转消除。

## 验证与交付

- 完整行为测试、手册原样例及 24 组原生 C 差分测试。
- 地址/未定义行为检查器下执行完整测试。
- 独立只读代码审查；输入输出文件别名保护作为审查发现补充。
- 报告复用实验一紫色章节样式，2 页，最小字号 11 pt。
- 最终 ZIP 顶层直接包含 Code/、report.pdf。八个源码文件，不包含生成的 C、目标文件、测试工具或报告源文件。
- 当前无课程官方虚拟机，Docker daemon 不可用；未宣称官方 VM/OJ 或 Ubuntu 全环境验证。

开发辅助文件不属于提交材料。实验一、实验二源码未因本实验而修改。
