协议栈：⽹络通信的分层模型
TC P/IP 是互联⽹的基础协议族，通常抽象为 4 层协议栈：
层次 名称 主要协议 作⽤
4 应⽤层 HTTP · FTP · DNS 为应⽤程序提供⽹络服务接⼝
3 传输层 TCP · U DP 端到端传输、差错控制、流量控制
2 ⽹络层 IP · ARP · ICMP 路由选择、拥塞控制、⽹络互连
1 ⽹络接⼝层SL IP · PPP · IEEE802 物理上的可靠数据传输
HTTP 属于应⽤层，提供超⽂本数据的传输；它构建在 TC P 连接之上

数据包：层层封装
当应⽤层发送数据时，TCP/IP 逐层封装，接收⽅逐层解包：
应⽤层    消息      │ Hello World │
                  ↓
传输层    段        │ TCP/UDP 头  │ Hello World │
                  ↓
⽹络层    包        │ IP 包头  │ TCP/UDP 头  │ Hello World │
                  ↓
⽹络接⼝  帧   │ MAC │ LLC │ IP 包头  │ TCP/UDP 头  │ Hello World │ FCS │
数据可能被拆分为多个包依次发送

HTTP 协议：客户端-服务器模型
HTTP（HyperText Transfer Protocol） 是应⽤层协议，采⽤ C/S 模型：
客户端  (Browser)          服务端  (Server)
       │                        │
       │──── HTTP Request ──────►│
       │                        │  处理请求
       │◄─── HTTP Response ──────│
       │                        │
HTTP ⽆状态特性：
⾮ Keep-Alive 模式：每次请求建⽴新连接，响应后关闭，服务器不保留连接信息
Keep-Alive 模式：Connection: Keep-Alive  头使连接持续有效，节省建连开销

HTTP ⼯作流程
⼀次 HTTP 操作（事务）的完整过程：
1. 地址解析
   URL: http://localhost.com:8080/index.htm
        协议名     主机名         端⼝   路径
   → DNS 解析域名  → 获得服务器  IP 地址
2. 封装  HTTP 请求数据包
   → 结合本机信息，构建请求报⽂
3. 建⽴  TCP 连接（三次握⼿）
   → HTTP 默认端⼝  80 ， Spring Boot 开发常⽤  8080
4. 客户端发送请求
   GET /sample/hello.jsp HTTP/1.1
5. 服务器响应
   HTTP/1.1 200 OK  + 响应头  + 空⾏  + 响应体
6. 关闭  TCP 连接（或  Keep-Alive 保持）

URL ：统⼀资源定位符
URL （Uniform Resource Locator） 是互联⽹上资源的标准地址，如同⽹络上的⻔牌号：
  http://  blog.example.com  :8080  /users  ?gender=male&page=1
  ↑ 协议名    ↑ 主机名（域名）    ↑ 端⼝   ↑ 路径    ↑ 查询参数（键值对）
协议：http  / https （加密）
主机名：通过 DNS 解析为服务器 IP 地址
端⼝：HTTP 默认 80 ，HTTPS 默认 443 ，Spring Boot 开发常⽤ 8080
路径：服务器上的资源位置
查询参数：以 ?  开始，name=value  格式，多个参数⽤ &  分隔
示例：
GET /api/products/123/reviews?page=2&size=10&sort=time HTTP/1.1
    └── 路径：层次化资源  ──────┘   └── 过滤 / 分⻚参数  ──────────┘

为什么需要 MyBatis？
原始 JDBC 写法（繁琐、危险）：
Connection conn = DriverManager.getConnection(url, user, pass);
PreparedStatement ps = conn.prepareStatement(
    "SELECT * FROM website WHERE id = ?");
ps.setInt(1, id);
ResultSet rs = ps.executeQuery();
while (rs.next()) {
    site.setName(rs.getString("name"));   // ⼿动映射每个字段
    site.setUrl(rs.getString("url"));
}
rs.close(); ps.close(); conn.close();    // 忘记关闭  → 连接泄漏！
MyBatis 写法（简洁、安全）：
@Mapper
public interface WebSiteMapper {
    @Select("SELECT * FROM website WHERE id = #{id}")
    WebSite findById(Integer id);
}
M yBatis ⾃动处理：连接管理 · 参数预编译绑定 · 结果集映射 · 异常转换 30

MyBatis CRUD：注解写法
@Mapper
public interface WebSiteMapper {
    @Select("SELECT * FROM website")
    List<WebSite> findAll();
    @Select("SELECT * FROM website WHERE id = #{id}")
    WebSite findById(Integer id);
    @Insert("INSERT INTO website(name, url) VALUES(#{name}, #{url})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    int insert(WebSite site);
    @Update("UPDATE website SET name=#{name}, url=#{url} WHERE id=#{id}")
    int update(WebSite site);
    @Delete("DELETE FROM website WHERE id = #{id}")
    int delete(Integer id);
}
⚠  安全提示：#{id}  是预编译参数（防 SQL  注⼊），${id}  是字符串拼接（危险！永远别⽤于⽤户输⼊）

认证 vs 授权
概念 英⽂ 要回答的问题 举例
认证 Authentication（AuthN） 你是谁？ ⽤户名 + 密码登录
授权 Authorization（AuthZ） 你能做什么？管理员才能删除⽤户
Spring Security 的核⼼：过滤器链（Filter Chain）
HTTP 请求进来
  ├── UsernamePasswordAuthenticationFilter  ← 处理表单登录
  ├── JwtAuthenticationFilter               ← 验证  Token （⾃定义）
  ├── ExceptionTranslationFilter            ← 将异常转为  401 / 403 响应
  └── FilterSecurityInterceptor             ← 最终权限检查
  │
  ▼
Controller （只有通过全部过滤器才能到达）
核⼼设计：安全横切关注点——不侵⼊业务代码，全部在过滤器链中处理

SecurityFilterChain 配置
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http,
                                           JwtAuthFilter jwtFilter)
            throws Exception {
        http
            .csrf(csrf -> csrf.disable())           // REST API 场景关闭  CSRF
            .sessionManagement(s ->
                s.sessionCreationPolicy(STATELESS)) // JWT ⽆状态，不使⽤  Session
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()    // 登录 / 注册不需要认证
                .requestMatchers("/api/admin/**").hasRole("ADMIN") // 管理接⼝需要⻆⾊
                .anyRequest().authenticated()        // 其余接⼝均需认证
            )
            .addFilterBefore(jwtFilter,
                UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }
}

JW T 认证流程
客户端                                    服务端
  │                                        │
  │── POST /api/auth/login ───────────────►│
  │   { "username": "alice",               │ 1. 验证⽤户名  + 密码
  │     "password": "123456" }             │ 2. 查数据库， BCrypt ⽐对
  │                                        │ 3. ⽣成  JWT Token （有效期  24h ）
  │◄── { "token": "eyJhbG..." } ───────────│
  │                                        │
  │── GET /api/sites ─────────────────────►│
  │   Authorization: Bearer eyJhbG...      │ 4. 解析  Token Header
  │                                        │ 5. 验证签名  + 过期时间
  │◄── [{ "id":1, "name":"NJU" }, ...]  ───│ 6. 通过  → 执⾏业务逻辑
JW T 结构：Header.Payload.Signature （三段 Base64 ⽤ .  分隔）
eyJhbGciOiJIUzI1NiJ9              ← Header ：签名算法（ HS256 ）
.eyJ1c2VyIjoiYWxpY2UiLCJleHAiOjF9 ← Payload ：⽤户信息（ Base64 编码，⾮加密！）
.SflKxwRJSMeKKF2QT4fwpMeJf36POk6   ← Signature ：密钥  HMAC 签名，防篡改
⚠  JW T Payload 只是 Base64 编码，任何⼈都能解码——绝不要把密码存⼊ Payload！

UserDetailsService：连接 Security 与数据库
@Service
public class UserDetailsServiceImpl implements UserDetailsService {
    @Autowired
    private UserMapper userMapper;   // MyBatis Mapper ，从数据库查⽤户
    @Override
    public UserDetails loadUserByUsername(String username)
            throws UsernameNotFoundException {
        User user = userMapper.findByUsername(username);
        if (user == null) {
            throw new UsernameNotFoundException(" ⽤户不存在 : " + username);
        }
        // 构建  Spring Security ⽤户对象，供框架进⾏密码⽐对
        return org.springframework.security.core.userdetails.User
            .withUsername(user.getUsername())
            .password(user.getPassword())   // 数据库存的是  BCrypt 哈希值
            .roles(user.getRole())          // ⻆⾊： USER / ADMIN
            .build();
    }
}

登录与注册接⼝
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    @PostMapping("/login")
    public ResponseEntity<?> login(@RequestBody LoginRequest req) {
        // 1. 委托  Spring Security 验证⽤户名  + 密码
        Authentication auth = authManager.authenticate(
            new UsernamePasswordAuthenticationToken(
                req.getUsername(), req.getPassword()));
        // 2. 验证通过，⽣成  JWT Token （有效期  24h ）
        String token = jwtUtil.generateToken(auth.getName());
        return ResponseEntity.ok(Map.of("token", token));
    }
    @PostMapping("/register")
    public ResponseEntity<?> register(@RequestBody RegisterRequest req) {
        // 3. 注册时  BCrypt 加密密码再存⼊数据库
        String encoded = passwordEncoder.encode(req.getPassword());
        userMapper.insert(new User(req.getUsername(), encoded, "USER"));
        return ResponseEntity.ok(Map.of("message", " 注册成功 "));
    }
}
