HTTP 协议：客户端-服务器模型
HTTP（HyperText Transfer Protocol） 是应⽤层协议，采⽤ C/S 模型：
客户端  (Browser)          服务端  (Server)
       │                        │
       │──── HTTP Request ──────►│
       │                        │  处理请求
       │◄─── HTTP Response ──────│
       │                        │
HTTP ⽆状态特性：
⾮ Keep-Alive 模式：每次请求建⽴新连接，响应后关闭，服务器不保留连接信息
Keep-Alive 模式：Connection: Keep-Alive  头使连接持续有效，节省建连开销
