好提示词的四要素
公式：[ ⻆⾊ ] + [ 任务 ] + [ 约束 ] + [ 格式 ]
  差的提示词：
    " 帮我修  bug"
  好的提示词：
    " 作为⼀名熟悉  Java Spring Boot 的后端⼯程师，   [ ⻆⾊ ]
     分析以下代码中导致空指针异常的根本原因，           [ 任务 ]
     仅修改出错的⽅法，不要改动其他代码，               [ 约束 ]
     给出修复后的完整⽅法代码，并⽤⼀句话解释原因。 "   [ 格式 ]
核⼼原则：约束越精确，AI 的输出越可控
AI 不会⾃动猜测你的意图——它会忠实地执⾏你给的指令，哪怕指令有歧义
