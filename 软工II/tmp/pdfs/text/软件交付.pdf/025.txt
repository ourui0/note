大模型辅助用户文档自动生成
文档生成的核心挑战
软件更新快，文档滞后——「文档腐败」是最普遍的软件问题之一
手工撰写文档耗时，且往往缺乏示例和场景描述
大模型生成用户文档的典型流程
Step 1：输入 API 规格 / 源码注释 / 变更日志，LLM 生成初稿
Step 2：人工审核准确性，补充业务背景
Step 3：LLM 针对不同受众（用户 / 管理员）生成不同版本
Claude Code 实战：从代码到文档
$ claude "读取 src/api/ 目录，为每个 REST 端点生成 Markdown 格式的用户文档，
包含：功能描述、请求参数、响应示例、常见错误码"
生成结果直接写入 docs/api.md，并在每次代码变更时通过 Hook 自动触发更新
文档质量保障
AI 自动检测文档与代码的不一致（参数名变更、接口删除）
生成文档可读性评分，建议简化复杂句式，确保面向非技术用户
支持中英文双语文档自动生成，降低国际化成本
