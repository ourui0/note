# 数据的机器级表示

+ 用二进制编码的原因：
  + 制造两个稳定态的物理器件容易
  + 二进制编码、计数、运算规则简单
  + 正好与逻辑命题对应，便于逻辑运算，并可方便的用逻辑电路实现算术运算

+ 用八进制与十六进制的原因：
  + 便于阅读书写
  + 与二进制三者之间易转换
+ 进制表示：
  + 二进制：B
  + 八进制：O
  + 十进制：D
  + 十六进制：H
+ 十进制转二进制小数：*2取1
+ 负数的补码是正数补码的“各位取反、末尾加一”
+ LSB：最低有效位
+ MSB：最高有效位
+ 小端：低地址放低字节
+ 大端：低地址放高字节
+ IEEE 754标准：
  + 32位：符号s一位、阶码e八位，移码，编制2^(n-1) - 1= 127,尾数f 23位，源码，第一位为1，隐藏
  + 64位：符号s 1位，阶码e 11 位，移码，编制1023，尾数 f 52位，隐藏第一位1
+ 全0阶码全0尾数：+0/-0
+ 全1阶码全0尾数：+∞/-∞
+ 全1阶码非0尾数：NaN
+ 至少需要两个字节表示一个汉字内码
+ 字为16位，字长为32位
+ 容量为2的幂次方，带宽为10的幂次方
