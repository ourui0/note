大模型辅助代码评审
大模型在代码评审中的应用
• 自动检测代码坏味道：命名不规范、过长方法、魔法数字、重复代
码等
• 安全审查：识别缓冲区溢出、SQL注入、资源泄漏等常见漏洞
• 风格一致性：检查是否符合团队编码规范（Google Style / 阿里规约
等）
与传统评审结合的工作流
• ① 提交 PR 前，先用大模型进行自动化预审，修复明显问题
• ② 人工评审聚焦于架构、业务逻辑等大模型难以判断的维度
• ③ 大模型生成评审检查列表（Checklist），提升评审覆盖率
工具推荐
• GitHub Copilot Code Review、CodeRabbit（AI PR 评审）、SonarQube 
+ LLM 集成
注意事项
• 大模型评审结论需人工确认，不能完全替代同行评审，尤其是业务
逻辑正确性
