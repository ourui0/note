# 第06章 关系数据理论考前复习

参考：第06章讲义、关系数据理论复习、复习思考题12/13/14、数据管理基础期末练习（2026）。

## 一、样卷考法

第06章是样卷大题核心，主要考：

- 根据函数依赖集求极小函数依赖集 / 最小覆盖。
- 求候选码、主属性、非主属性。
- 3NF 分解，要求无损连接和保持函数依赖。
- 判断是否满足 BCNF，不满足则继续分解。
- 根据文字语义写函数依赖。
- 判断关系最高满足哪个范式。

## 二、基本概念

函数依赖 `X -> Y`：

在关系 `R` 的任意可能实例中，若两个元组在 `X` 上取值相同，则它们在 `Y` 上取值也相同。

平凡函数依赖：

```text
Y ⊆ X，则 X -> Y 是平凡函数依赖
```

非平凡函数依赖：

```text
Y ⊄ X，则 X -> Y 是非平凡函数依赖
```

完全函数依赖：

```text
X -> Y 成立，且 X 的任何真子集都不能决定 Y
```

部分函数依赖：

```text
X -> Y 成立，但 X 的某个真子集也能决定 Y
```

传递函数依赖：

```text
X -> Y, Y -> Z，且 Y 不决定 X，Z 不属于 Y
```

码相关：

- 超码：能唯一标识元组的属性集。
- 候选码：最小超码。
- 主属性：出现在任一候选码中的属性。
- 非主属性：不出现在任何候选码中的属性。

## 三、属性闭包

属性集闭包 `X+`：在函数依赖集 `F` 下，由 `X` 能推出的全部属性。

用途：

- 判断 `X` 是否为超码。
- 判断 `F` 是否蕴涵 `X -> Y`。
- 求候选码。

计算步骤：

1. 初始令 `X+ = X`。
2. 如果存在依赖 `A -> B`，且 `A ⊆ X+`，则把 `B` 加入 `X+`。
3. 重复直到 `X+` 不再增长。

例：

```text
R(A,B,C,D,E,F)
F = { A -> F, B -> DE, CD -> AB }
```

求 `(BC)+`：

```text
初始：BC
B -> DE，得到 BCDE
CD -> AB，已有 C,D，得到 ABCDE
A -> F，得到 ABCDEF
```

所以 `BC` 是超码。若 `B+`、`C+` 都不能推出全部属性，则 `BC` 是候选码。

## 四、候选码求法

常用步骤：

1. 找只出现在左部、不出现在右部的属性，这些属性通常必须包含在候选码中。
2. 找从不出现在任何函数依赖中的属性，这些属性也必须包含在候选码中。
3. 从必含属性出发，逐步补属性，计算闭包。
4. 能推出全部属性且最小，就是候选码。

例题：样卷规范化第2题。

```text
T(A,B,C,D,E,F)
F = { A -> F, B -> DE, CD -> AB }
```

候选码：

```text
BC 和 CD
```

验证：

```text
(BC)+:
BC -> B -> DE，得 BCDE
CD -> AB，得 ABCDE
A -> F，得 ABCDEF
所以 BC 是码。

(CD)+:
CD -> AB，得 ABCD
B -> DE，得 ABCDE
A -> F，得 ABCDEF
所以 CD 是码。
```

主属性：

```text
B, C, D
```

非主属性：

```text
A, E, F
```

## 五、范式判断

1NF：

- 所有属性都是不可再分的原子值。

2NF：

- 在 1NF 基础上，每个非主属性完全函数依赖于每一个候选码。
- 主要消除非主属性对复合候选码的部分依赖。

3NF：

对每个非平凡依赖 `X -> A`，满足至少一个：

- `X` 是超码。
- `A` 是主属性。

BCNF：

对每个非平凡依赖 `X -> Y`：

- `X` 必须是超码。

区别：

- 3NF 允许右部是主属性的依赖左部不是超码。
- BCNF 更严格，只看左部是不是超码。

4NF：

对每个非平凡多值依赖 `X ->> Y`：

- `X` 必须是超码。

## 六、极小函数依赖集 / 最小覆盖

目标：找一个与原依赖集等价的依赖集，满足：

- 右部都是单属性。
- 左部没有多余属性。
- 没有多余函数依赖。

算法：

1. 分解右部：`X -> A1A2` 改为 `X -> A1`、`X -> A2`。
2. 消除左部多余属性。
3. 消除冗余函数依赖。
4. 可按相同左部重新合并右部。

### 例题1：样卷规范化第1题

```text
S(A,B,C,D,E,F)
F = { A -> E, B -> ADE, DF -> AC, ADF -> B }
```

极小函数依赖集：

```text
{ A -> E, B -> AD, DF -> BC }
```

关键过程：

1. 分解右部：

```text
A -> E
B -> A
B -> D
B -> E
DF -> A
DF -> C
ADF -> B
```

2. 化简左部：

```text
ADF -> B 可化简为 DF -> B
```

3. 删除冗余依赖：

```text
B -> E 可由 B -> A 和 A -> E 推出，删除。
DF -> A 可由 DF -> B 和 B -> A 推出，删除。
```

得到：

```text
A -> E
B -> A
B -> D
DF -> C
DF -> B
```

合并相同左部：

```text
{ A -> E, B -> AD, DF -> BC }
```

### 例题2：复习题13

```text
M = { ABD -> AC, C -> BE, AD -> BF, B -> E }
```

计算思路：

1. 分解右部：

```text
ABD -> A
ABD -> C
C -> B
C -> E
AD -> B
AD -> F
B -> E
```

其中 `ABD -> A` 是平凡依赖，可删。

2. 检查 `ABD -> C` 左部是否有多余属性：

```text
可化简为 AD -> C
```

3. 继续检查各依赖左部和冗余依赖，得到极小覆盖。

考试技巧：

- 右部先拆单属性。
- 平凡依赖直接删。
- 检查左部某属性是否多余时，用去掉该属性后的闭包判断能否推出右部。

## 七、3NF 分解

基于最小覆盖的 3NF 分解步骤：

1. 先求极小函数依赖集。
2. 对每个依赖 `X -> Y` 建一个关系 `XY`。
3. 如果多个依赖左部相同，可以合并为一个关系。
4. 如果没有任何关系包含原关系的候选码，补充一个包含候选码的关系。
5. 如果某个关系属性集被另一个关系包含，可以删除较小关系。

特点：

- 通常保持函数依赖。
- 可保证无损连接。

### 例题：样卷规范化第2题

```text
T(A,B,C,D,E,F)
F = { A -> F, B -> DE, CD -> AB }
```

候选码：

```text
BC, CD
```

3NF 分解：

```text
R1(A, F)
R2(B, D, E)
R3(A, B, C, D)
```

说明：

- `A -> F` 生成 `R1(A,F)`。
- `B -> DE` 生成 `R2(B,D,E)`。
- `CD -> AB` 生成 `R3(C,D,A,B)`。
- `R3` 包含候选码 `CD`，所以无损连接。
- 各依赖都能在某个子关系中检查，所以保持依赖。

## 八、BCNF 判断与分解

BCNF 判断：

逐条检查非平凡函数依赖 `X -> Y`，若 `X` 不是超码，则违反 BCNF。

BCNF 分解方法：

若 `R` 中有依赖 `X -> Y` 违反 BCNF，则分解为：

```text
R1 = X ∪ Y
R2 = R - (Y - X)
```

### 例题：继续样卷第2题

3NF 分解结果：

```text
R1(A,F)
R2(B,D,E)
R3(A,B,C,D)
```

判断：

- `R1(A,F)` 中 `A -> F`，`A` 是码，满足 BCNF。
- `R2(B,D,E)` 中 `B -> DE`，`B` 是码，满足 BCNF。
- `R3(A,B,C,D)` 中有依赖：

```text
CD -> AB
B -> D
```

`R3` 的候选码是：

```text
BC, CD
```

`B -> D` 中 `B` 不是超码，违反 BCNF。

分解 `R3`：

```text
R31(B,D)
R32(A,B,C)
```

但 `R31(B,D)` 的属性被 `R2(B,D,E)` 包含，可不保留。最终 BCNF 分解：

```text
R1(A,F)
R2(B,D,E)
R3(A,B,C)
```

注意：BCNF 分解通常无损连接，但可能不保持全部函数依赖。

## 九、无损连接与依赖保持

无损连接：

分解后的关系自然连接后能还原原关系，不产生伪元组。

二元分解 `R -> R1, R2` 的常用判定：

```text
(R1 ∩ R2) -> R1
或
(R1 ∩ R2) -> R2
```

若成立，则该二元分解无损。

依赖保持：

分解后各关系上的函数依赖投影合起来，能够推出原函数依赖集。

区别：

- 3NF 分解通常可同时无损并保持依赖。
- BCNF 分解通常保证无损，但不一定保持依赖。

## 十、根据文字描述写函数依赖

做法：

1. 找“唯一确定”的语句。
2. 找“同一时间只能”“每门课只安排一场”等约束。
3. 把语义翻译为左部决定右部。

### 例题：样卷监考安排

关系：

```text
T(cno, sdate, room, tno)
```

语义：

1. 每门课期末考试只安排一场。
2. 同一时间，一位监考老师只能在指定一间教室监考一门课。
3. 同一时间，一间教室只能安排一门课程考试。

函数依赖：

```text
cno -> sdate
(sdate, room) -> cno
(sdate, tno) -> room
```

候选码：

```text
(tno, cno)
(tno, sdate)
```

理由：

```text
(tno, cno)+:
cno -> sdate，得 sdate
(sdate, tno) -> room，得 room
推出全部属性。

(tno, sdate)+:
(sdate, tno) -> room，得 room
(sdate, room) -> cno，得 cno
推出全部属性。
```

范式：

- 主属性：`tno, cno, sdate`
- 非主属性：`room`
- 不存在违反 2NF 和 3NF 的依赖。
- `cno -> sdate` 中 `cno` 不是超码，违反 BCNF。

所以最高满足：

```text
3NF，不满足 BCNF
```

## 十一、多值依赖与 4NF

多值依赖 `X ->> Y`：

在给定 `X` 后，`Y` 的一组取值与其余属性的一组取值相互独立组合。

典型例子：

```text
Teaching(Course, Teacher, Book)
```

若一门课程有多个教师和多本参考书，教师集合与参考书集合彼此独立，则：

```text
Course ->> Teacher
Course ->> Book
```

会产生组合冗余。

4NF：

对每个非平凡多值依赖 `X ->> Y`，`X` 必须是超码。

如果不满足，可分解为：

```text
R1(X, Y)
R2(X, 其余属性)
```

## 十二、考前速查

最小覆盖：

```text
拆右部 -> 删左部多余属性 -> 删冗余依赖 -> 合并同左部
```

候选码：

```text
找必含属性 -> 算闭包 -> 最小化
```

3NF 判断：

```text
每个 X -> A：X 是超码 或 A 是主属性
```

BCNF 判断：

```text
每个 X -> Y：X 必须是超码
```

3NF 分解：

```text
每个依赖建关系；补候选码；删被包含关系
```

BCNF 分解：

```text
找违反依赖 X -> Y
分解为 XY 和 R-(Y-X)
```

文字题翻译：

```text
唯一、只能、有且只有一个  -> 函数依赖
多组独立取值              -> 多值依赖
```
