## 1　实现功能与选做范围

在实验一、二的词法分析、语法分析和语义检查基础上，将符合实验三假设的 C-- 整数程序翻译为线性三地址中间代码。支持局部变量及初始化、赋值与四则运算、比较与逻辑运算、if/else、while、函数定义、递归调用、返回值，以及必做的一维数组访问。

实验三仅实现选做 3.2：一维数组可作为函数参数，以地址传递，函数内修改会作用于调用者的数组；支持局部多维数组，按 C 风格连续存储计算各维偏移。多维数组本身不作为函数形参或返回值，符合选做范围。

未实现选做 3.1。遇到结构体类型输入时，向 stdout 输出手册规定的提示：Cannot translate: Code contains variables or parameters of structure type.，不生成结构体中间代码。浮点类型不在本实验支持范围内。

预定义 read() 和 write(int) 分别翻译为 READ 和 WRITE；read 返回读入的整数，write 的返回值为 0。正常翻译结果写入命令行指定的输出文件，每行一条指令，不再打印语法树。

## 2　实现方法与亮点

分离检查与生成。parser.y 构造语法树，semantic.c 检查语义并登记内置函数，ir.c 遍历语法树生成指令链表。全部翻译完成后统一输出，便于进行局部优化。源变量、临时量与标号分别使用 v、t、label 加编号，避免与原标识符冲突。

统一寻址。数组类型记录总字节数和元素类型，整型宽度为 4 字节。局部数组使用 DEC 申请空间，访问 a[i] 时计算“基址 + i × 元素宽度”；元素仍为数组时继续返回地址，否则用解引用指令读写整数。例如 int a[2][3] 中，a[i][j] 的偏移为 i × 12 + j × 4。一维数组形参直接保存地址，转传参数时不会再次取该参数变量的地址。

保持求值与控制流语义。逻辑与、或、非使用真假目标标号实现短路；作为普通表达式时转成 0 或 1。实参先按源码顺序求值并保存，再逆序输出 ARG，与正序 PARAM 对应；嵌套调用先完成内层调用，避免实参混淆。赋值前保存数组元素地址，防止右侧表达式改变下标后写入错误位置。

保守优化。整数常量表达式在安全范围内折叠，立即数直接参与运算，简化加减零与乘一，并删除跳向紧邻标号的 GOTO。优化保留 read、write、赋值和函数调用等副作用，不跨控制流传播变量值。

## 3　编译与运行

ZIP 解压后顶层为 Code/ 和 report.pdf。Code/ 含 parser.h、parser.c、lexer.l、parser.y、semantic.h、semantic.c、ir.h、ir.c 八个源码文件。使用支持 C99 的 GCC、GNU Flex 和 GNU Bison，不依赖第三方 C 库。

在解压目录逐条执行：

```text
cd Code
flex -o lex.yy.c lexer.l
bison -d -o syntax.tab.c parser.y
gcc -std=c99 -Wall -Wextra parser.c semantic.c \
    ir.c syntax.tab.c -o parser
./parser input.cmm output.ir
```

input.cmm 为输入程序，output.ir 为中间代码输出文件，二者路径均相对于当前目录。parser.y 包含 lex.yy.c，因此不要再单独编译 lex.yy.c。词法器使用 noyywrap，程序提供 main 和 yyerror，上述命令无需额外链接 libfl 或 liby。

也可将课程 Makefile_ref 复制为 Code/Makefile 后执行 make。该文件自动发现 semantic.c 和 ir.c，最后使用 -lfl -ly 链接，因此需要课程 Linux 环境中的对应运行库。本地缺少运行库时使用上面的逐条命令。实验一继承的语法恢复规则会产生 Bison 冲突警告，但不阻止生成和编译。

翻译成功时 stdout 保持为空，IR 写入 output.ir。词法、语法、语义错误及不支持功能的提示写入 stdout，不写入 IR；源文件分析正常结束时返回 0。参数错误、文件无法打开或输出写入失败时返回非零值。

## 4　测试与验证

测试采用“生成 IR—解释执行—比较结果”的流程，检查整数运算、六种关系运算、短路副作用、循环、递归、嵌套函数调用、实参顺序、多维寻址和数组引用传递。手册必做样例分别验证符号函数的正、零、负输入及阶乘；选做 3.2 原样例输出 1、3，未选的结构体原样例输出拒绝提示。

另有 24 组固定种子的标量与矩阵程序，同时运行原生 C 编译结果和生成的 IR，比较输出。包含输入输出文件别名保护在内，完整回归共 63 项，另使用地址和未定义行为检查器验证编译器运行。打包后再次从 ZIP 解压源码并运行同一组测试。

本地验证环境为 macOS。测试解释器按手册指令格式实现；当前课程目录未提供官方虚拟机，因此尚未进行官方虚拟机或 OJ 验证。提交以平台预测试和最终测试结果为准。
