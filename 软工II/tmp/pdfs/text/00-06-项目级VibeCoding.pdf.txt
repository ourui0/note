后端代码示例
Claude Code ⽣成的核⼼路由结构：
// src/routes/tasks.js
const express = require('express');
const router  = express.Router();
const db      = require('../db');
// 获取所有任务（⽀持按  status 过滤）
router.get('/', (req, res) => {
  const { status } = req.query;
  const tasks = status
    ? db.prepare('SELECT * FROM tasks WHERE status = ?').all(status)
    : db.prepare('SELECT * FROM tasks ORDER BY created_at DESC').all();
  res.json(tasks);
});
// 新建任务
router.post('/', (req, res) => {
  const { title, priority, assignee, dueDate } = req.body;
  const result = db.prepare(
    'INSERT INTO tasks (title, status, priority, assignee, due_date) VALUES (?,?,?,?,?)'
  ).run(title, 'todo', priority, assignee, dueDate);
  res.status(201).json({ id: result.lastInsertRowid });
});
module.exports = router; 19

接⼊ AI 能⼒：调⽤ API Key
让后端具备 AI 功能（以 Gemini API 为例）：
在后端新增⼀个接⼝ POST /api/ai/suggest ，
接收任务标题，调⽤ Google Gemini API，

API Key 从环境变量 GEMINI_API_KEY  读取。
// Claude Code ⽣成的  AI 接⼝
const { GoogleGenerativeAI } = require('@google/generative-ai');
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);
router.post('/suggest', async (req, res) => {
  const { title } = req.body;
  const model  = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });
  const result = await model.generateContent(
    ` 将以下任务分解为  3-5 个⼦步骤，⽤中⽂回答：${title}`
  );
  res.json({ steps: result.response.text() });
});

什么是 MCP？
M CP（Model Context Protocol）：AI 与⼯具之间的标准通信协议
由 Anthropic 提出，已成为 AI ⼯具集成的事实标准
允许 AI（Claude Code / 灵码 等）直接调⽤外部⼯具
每个 M CP Server 赋予 AI ⼀种新能⼒，按需开启
AI Agent (Claude Code)
      MCP 协议
┌─────────────────────────────────────┐
│  chrome-devtools  →  读取浏览器状态   │
│  github           →  操作  GitHub     │
│  vercel           →  ⼀键部署         │
│  mcp-server-sqlite →  查询数据库      │
│  mcp-server-chart  →  ⽣成图表        │
└─────────────────────────────────────┘
过去：AI 看不到浏览器⾥发⽣了什么，只能根据你的⽂字描述来猜测问题。现在：AI 可以直接读取控制台报错、⽹络请
求、DO M  结构。
