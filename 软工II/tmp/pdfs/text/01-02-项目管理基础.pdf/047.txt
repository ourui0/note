GitO ps：以 Git 为中⼼的运维范式
开发者  ──push──  Git 仓库（唯⼀事实源）
                        │
                  GitOps 控制器（ ArgoCD / Flux ）持续监听
                        │
                        ▼
              ┌─────────────────────┐
              │  实际环境  ≠ 声明？     │
              │  → ⾃动同步到期望状态   │
              │  → 告警  + 审计⽇志     │
              └─────────────────────┘
GitO ps 四⼤原则：
原则 说明 Knight Capital 教训映射
Git 是唯⼀事实源所有环境配置都在 Git 仓库中声明 不再有"记不清哪台装了什么"
声明式⽽⾮命令式描述"期望状态"⽽⾮"操作步骤" 消除⼿动操作遗漏
⾃动同步 系统⾃动将实际状态与 Git 声明对⻬ 不⼀致⽴即被修复
可审计 git log 即完整变更审计⽇志 每次变更都有记录和责任⼈
