# 中国近现代史纲要期末复习重点（2023版教材向）

> 背诵建议：名词解释按“时间+人物/事件+内容+影响”答；问答/论述按“背景原因-主要经过/内容-历史影响/局限”答；材料题先扣材料，再联系教材结论。

## 1. 鸦片战争：主要内容与爆发原因

**时间与经过**

1. 时间：1840年至1842年。
2. 性质：英国发动的侵略中国的战争。
3. 爆发：1840年6月，英国舰队到达中国海面，封锁珠江口，鸦片战争正式爆发。
4. 经过：英军沿海北上，先后攻占定海、厦门、宁波、乍浦、吴淞等地。
5. 结果：1842年8月，英军到达南京江面，清政府被迫求和。

**爆发原因**

1. 根本原因：英国完成工业革命后，急需扩大海外市场和原料产地，企图用武力打开中国大门。
2. 直接原因：英国向中国走私鸦片，造成白银外流、财政困难、人民身心受害；林则徐虎门销烟维护国家利益和民族尊严，英国以此为借口发动战争。
3. 中国方面原因：清政府政治腐败、军事落后、闭关自守，难以抵御西方资本主义侵略。

**影响**

1. 中国被迫签订《南京条约》等不平等条约。
2. 中国领土主权、关税主权、贸易主权等遭到破坏。
3. 中国开始由封建社会逐步变为半殖民地半封建社会。
4. 鸦片战争成为中国近代史的开端。

## 2. 《南京条约》《马关条约》《辛丑条约》

### 《南京条约》

**签订原因**

1. 鸦片战争中清政府战败。
2. 英国以武力迫使清政府接受不平等条件。

**主要内容**

1. 时间：1842年签订，是中国近代史上第一个不平等条约。
2. 割地：割香港岛给英国。
3. 赔款：赔款2100万银元。
4. 通商：开放广州、厦门、福州、宁波、上海五处为通商口岸。
5. 关税：英商进出口货物税率由中英协定。

**后果**

1. 破坏中国领土主权。
2. 破坏中国关税自主权和贸易主权。
3. 便利英国商品倾销和经济侵略。
4. 中国开始沦为半殖民地半封建社会。

### 《马关条约》

**签订原因**

1. 1894年至1895年甲午中日战争中清政府惨败。
2. 日本借军事胜利强迫清政府签订不平等条约。

**主要内容**

1. 割地：割让辽东半岛、台湾全岛及其附属岛屿、澎湖列岛。
2. 赔款：赔款白银2亿两，另有赎辽费等负担。
3. 通商：开放沙市、重庆、苏州、杭州等通商口岸。
4. 设厂：允许日本在中国通商口岸投资设厂。

**后果**

1. 大大加深中国半殖民地化程度。
2. 割让台湾等地，严重破坏中国领土完整。
3. 巨额赔款加重清政府财政危机和人民负担。
4. 允许设厂，标志列强对华经济侵略由商品输出进一步转向资本输出。
5. 刺激列强瓜分中国的野心，激发新的救亡图存运动。

### 《辛丑条约》

**签订原因**

1. 1900年八国联军侵华。
2. 清政府战败，被迫于1901年签订。

**主要内容**

1. 赔款：赔款白银4.5亿两，分39年还清，本息近10亿两。
2. 驻兵：划定北京使馆区，允许外国驻兵；允许外国军队在北京至山海关沿线驻守。
3. 军事控制：拆毁大沽炮台。
4. 政治控制：严禁中国人民参加反帝活动。
5. 屈辱外交：清政府向列强表示“道歉”等。

**后果**

1. 中国主权进一步遭到严重破坏。
2. 财政负担空前沉重。
3. 清政府完全成为帝国主义统治中国的工具。
4. 标志中国半殖民地半封建社会完全形成。

## 3. 金田起义：主要内容与发生原因

**发生原因**

1. 阶级压迫：清政府赋税沉重，官吏横征暴敛，农民负担加重。
2. 战争赔款：鸦片战争后，清政府为支付赔款和弥补财政亏空加重搜刮。
3. 经济冲击：外国资本主义入侵使自然经济逐渐解体。
4. 鸦片危害：鸦片泛滥造成银贵钱贱，进一步加剧人民困苦。
5. 社会矛盾：阶级矛盾和民族矛盾激化，农民反抗斗争不断发展。

**主要内容**

1. 组织基础：洪秀全创立拜上帝教，利用宗教形式发动和组织群众。
2. 起义爆发：1851年1月，洪秀全率众在广西桂平县金田村起义。
3. 建号：起义军建号太平天国。
4. 发展：起义军从广西经湖南、湖北、江西、安徽进军江苏。
5. 建都：1853年攻占南京，改名天京，建立太平天国农民政权。

**意义**

1. 揭开太平天国农民战争序幕。
2. 沉重打击清王朝和封建统治秩序。
3. 体现农民反压迫、反剥削的强烈愿望。

## 4. 洋务运动大致内容

**背景与目的**

1. 时间：19世纪60年代至90年代。
2. 背景：第二次鸦片战争后，清政府面临内忧外患。
3. 代表人物：奕䜣、曾国藩、李鸿章、左宗棠、张之洞等。
4. 目的：学习西方科学技术，兴办洋务，以“自强”“求富”挽救清朝统治危机。

**指导思想**

1. 核心口号：“中学为体，西学为用”。
2. 含义：以封建伦理纲常和政治制度为根本，以西方技术为辅助。
3. 本质：学习西方器物技术，但不改变封建制度。

**主要内容**

1. 创办近代军事工业：如安庆军械所、江南制造总局、福州船政局、天津机器局、湖北枪炮厂。
2. 创办民用企业：如轮船招商局、开平矿务局、天津电报局、上海机器织布局。
3. 建立新式海陆军：改用洋枪洋炮，建立福建、广东、南洋、北洋水师。
4. 兴办新式教育：创办新式学堂，派遣留学生，培养翻译、军事、科技人才。

**评价**

1. 积极作用：客观上促进中国早期工业和民族资本主义发展。
2. 教育作用：推动近代教育起步，传播近代科技知识。
3. 思想作用：冲击传统“重本抑末”等观念，改变部分社会风气。
4. 失败原因：具有封建性，依赖列强，企业管理腐败，没有触动封建制度。
5. 失败标志：甲午战争中北洋海军覆没，标志洋务运动失败。

## 5. 戊戌变法：内容和经过

**背景**

1. 民族危机：甲午战败和《马关条约》签订后，民族危机加深。
2. 经济基础：民族资本主义初步发展。
3. 阶级要求：资产阶级维新派要求学习西方政治制度，发展资本主义。
4. 目标：通过变法维新实现救亡图存。

**宣传与酝酿**

1. 代表人物：康有为、梁启超、谭嗣同、严复等。
2. 上书：康有为等发起“公车上书”。
3. 著书立说：康有为写《新学伪经考》《孔子改制考》，梁启超写《变法通议》，严复翻译《天演论》等。
4. 组织宣传：办学会、设学堂、办报纸，传播维新思想。
5. 思想论战：维新派与守旧派围绕要不要变法、要不要兴民权设议院、要不要废八股改科举展开论战。

**主要内容**

1. 开始：1898年6月11日，光绪帝颁布“明定国是”诏，开始变法，史称“百日维新”。
2. 政治方面：改革行政机构，裁撤冗员，允许上书言事。
3. 经济方面：奖励农工商业，设农工商总局，修铁路，办邮政。
4. 军事方面：裁减旧军，训练新军。
5. 文化教育方面：创办京师大学堂，废八股，改试策论，派人留学，鼓励办报和学会。

**结果与评价**

1. 失败经过：1898年9月21日，慈禧太后发动戊戌政变，囚禁光绪帝，捕杀维新人士。
2. 代表牺牲：谭嗣同等“戊戌六君子”遇害。
3. 性质：戊戌变法是爱国救亡运动、资产阶级改良运动和思想启蒙运动。
4. 局限：没有触动封建制度根本，缺乏可靠的社会力量和政治力量。

## 6. 清末新政的主要内容

**背景**

1. 1901年《辛丑条约》后，清政府统治危机加深。
2. 国内要求变革的呼声高涨。
3. 清政府为延续统治，宣布实行“新政”。

**主要内容**

1. 改革官制：设立商部、学部、巡警部等中央行政机构。
2. 编练新军：裁撤绿营，建立新军。
3. 奖励工商：颁布商法商律，鼓励工商业发展。
4. 改革教育：鼓励留学，颁布新学制，1906年正式废除科举。
5. 预备立宪：1906年宣布“预备仿行宪政”，1908年颁布《钦定宪法大纲》，规定九年预备立宪。

**评价**

1. 客观作用：推动新军、新式教育、民族资本主义和新知识分子发展。
2. 根本目的：维护皇权和清朝统治。
3. 失败表现：皇族内阁等做法暴露其假立宪本质。
4. 历史后果：激化社会矛盾，加速清王朝灭亡。

## 7. 辛亥革命的经过

**历史条件**

1. 民族危机和社会矛盾加深。
2. 清末新政破产，清政府统治难以维持。
3. 民族资本主义发展，民族资产阶级和知识分子成为革命力量。
4. 孙中山等革命派传播民主革命思想，建立兴中会、中国同盟会。
5. 革命派提出三民主义，推动革命发展。

**主要经过**

1. 起义爆发：1911年10月10日晚，武昌新军中的革命党人发动起义。
2. 首义胜利：起义军攻占武昌，三天内光复武汉三镇，成立湖北军政府。
3. 全国响应：全国多省宣布独立，清王朝统治迅速瓦解。
4. 民国建立：1912年1月1日，孙中山在南京就任临时大总统，中华民国临时政府成立。
5. 清帝退位：1912年2月12日，清帝退位，延续两千多年的封建君主专制制度结束。

**成果与局限**

1. 推翻清王朝，结束封建君主专制制度。
2. 建立资产阶级共和国，使民主共和观念深入人心。
3. 推动社会风俗变化和思想解放。
4. 局限：革命果实被袁世凯窃取。
5. 局限：没有改变中国半殖民地半封建社会性质，没有完成反帝反封建任务。

## 8. 五四运动：原因和经过

**原因**

1. 社会力量：一战期间中国民族资本主义发展，工人阶级壮大。
2. 思想基础：新文化运动推动思想解放，先进青年知识分子成为骨干。
3. 国际影响：俄国十月革命影响中国。
4. 直接导火线：1919年巴黎和会上中国外交失败，列强决定把德国在山东的特权转交日本，北洋政府准备签字。

**经过**

1. 爆发：1919年5月4日，北京学生在天安门前集会游行。
2. 口号：提出“外争主权、内除国贼”“取消二十一条”“还我青岛”等口号。
3. 扩大：北洋政府镇压学生后，6月起上海工人罢工，商人罢市、学生罢课。
4. 转变：运动中心由北京转到上海，主力由学生转为工人。
5. 结果：北洋政府释放被捕学生，罢免曹汝霖、章宗祥、陆宗舆，中国代表拒绝在巴黎和约上签字。

**意义**

1. 是彻底反帝反封建的伟大爱国革命运动。
2. 是广泛群众参加的社会革命运动。
3. 是传播新思想新文化的思想启蒙运动。
4. 促进马克思主义传播及其同中国工人运动结合。
5. 为中国共产党成立准备思想和干部条件。
6. 是中国新民主主义革命的开端。
7. 五四精神的核心是爱国主义。

## 9. 国共合作的内容

**第一次国共合作**

1. 背景：二七惨案后，中国共产党认识到必须联合孙中山领导的国民党。
2. 中共三大：1923年决定共产党员以个人身份加入国民党。
3. 独立原则：共产党员加入国民党时，党必须保持政治、思想、组织上的独立性。
4. 国民党一大：1924年召开，重新解释三民主义，形成新三民主义。
5. 政策基础：事实上确立联俄、联共、扶助农工三大政策。
6. 形成标志：国民党一大标志第一次国共合作正式形成。
7. 作用：推动工农运动、黄埔军校建立和北伐战争，掀起大革命高潮。

**第二次国共合作**

1. 背景：日本侵略加深，停止内战、一致抗日成为全国要求。
2. 重要转折：西安事变和平解决，为合作创造条件。
3. 卢沟桥事变后：中共发表国共合作宣言，推动抗日民族统一战线。
4. 军队改编：红军改编为八路军、新四军。
5. 正式形成：1937年9月国民党公布中共宣言，蒋介石发表承认共产党合法地位的谈话。
6. 意义：以第二次国共合作为基础的抗日民族统一战线正式形成。

## 10. 南昌起义和秋收起义

### 南昌起义

**背景**

1. 1927年大革命失败。
2. 国民党反动派屠杀共产党人和革命群众。
3. 中国共产党认识到必须独立掌握革命武装。

**组织与发动**

1. 时间：1927年8月1日。
2. 地点：江西南昌。
3. 领导机构：以周恩来为书记的前敌委员会。
4. 主要领导人：周恩来、贺龙、叶挺、朱德、刘伯承等。
5. 参战力量：党掌握和影响的军队两万多人。

**意义**

1. 打响武装反抗国民党反动派的第一枪。
2. 是中国共产党独立领导革命战争的开端。
3. 是创建人民军队和武装夺取政权的开端。

### 秋收起义

**组织与发动**

1. 时间：1927年9月9日。
2. 地点：湘赣边界。
3. 领导人：毛泽东等。
4. 旗帜：公开打出“工农革命军”的旗帜。

**经过**

1. 起义军攻打长沙受挫。
2. 毛泽东决定向敌人力量薄弱的农村转移。
3. 1927年9月29日，在江西永新三湾村进行三湾改编。
4. 三湾改编从组织上确立党对军队的领导。
5. 1927年10月，到达井冈山，开始创建农村革命根据地。

**意义**

1. 实现从进攻大城市到向农村进军的转变。
2. 成为探索农村包围城市、武装夺取政权道路的重要开端。
3. 为创建井冈山革命根据地奠定基础。

## 11. 遵义会议的原因与历史转折

**原因**

1. 第五次反“围剿”失败后，中央红军被迫长征。
2. 长征初期，“左”倾错误领导继续造成严重损失。
3. 湘江战役后，中央红军由8.6万余人锐减到3万多人。
4. 党和红军面临生死危机，党内要求纠正错误领导。

**会议内容**

1. 时间：1935年1月15日至17日。
2. 地点：贵州遵义。
3. 性质：中共中央政治局扩大会议。
4. 中心议题：集中解决当时最紧迫的军事和组织问题。
5. 组织变化：增选毛泽东为中央政治局常委。
6. 会后安排：逐步形成毛泽东、周恩来、王稼祥三人军事指挥小组。

**实现的变化**

1. 事实上确立毛泽东在党中央和红军的领导地位。
2. 开始确立以毛泽东为主要代表的正确路线在党中央的领导地位。
3. 开始形成第一代中央领导集体。
4. 在危急关头挽救了党、挽救了红军、挽救了中国革命。
5. 是党的历史上生死攸关的转折点。
6. 开启中国共产党独立自主解决中国革命实际问题的新阶段。

## 12. 西南联大

**构成与地点**

1. 背景：抗日战争时期，为保存教育力量。
2. 构成：北京大学、清华大学、南开大学。
3. 地点：云南昆明。
4. 名称：三校合并组建国立西南联合大学。

**意义**

1. 体现抗战时期中国知识界坚持教育、科研和文化传承的精神。
2. 为民族独立和国家复兴培养大批人才。
3. 是战时中国高等教育的重要象征。

## 13. 卢沟桥事变

**时间与经过**

1. 时间：1937年7月7日夜。
2. 地点：北平卢沟桥附近。
3. 借口：日军借口一名士兵失踪，要求进入宛平县城搜查。
4. 爆发：遭中国守军拒绝后，日军炮轰宛平城，进攻中国驻军。

**影响**

1. 卢沟桥事变又称七七事变。
2. 标志日本全面侵华战争开始。
3. 中国由此进入全民族抗战阶段。
4. 中国开辟了世界反法西斯战争的东方主战场。

## 14. 世界反法西斯力量对中国抗战的支持

**总体概括**

1. 中国抗日战争是世界反法西斯战争的重要组成部分。
2. 中国战场是世界反法西斯战争的东方主战场。
3. 中国抗战得到爱好和平与正义的国家、人民、国际组织和反法西斯力量支持。

**主要表现**

1. 苏联援助：苏联最早为中国抗战提供援助；1937年中苏签订互不侵犯条约；苏联提供大量物资援助。
2. 苏联军事支持：2000多名苏联飞行员参加援华志愿航空队；抗战后期苏联红军进入中国东北，加速日本失败。
3. 美国支持：太平洋战争前后，美国转向支持中国、联合中国抗日。
4. 美国航空援助：陈纳德组织美国援华志愿航空队，并开辟驼峰航线。
5. 英法等国：提供经济援助或开展军事合作。
6. 国际医疗救援：加拿大医生白求恩、印度医生柯棣华等来华救死扶伤。
7. 国际人道援助和宣传：拉贝、辛德贝格等保护难民，国际记者积极报道中国抗战。

**意义**

1. 增强了中国抗战力量。
2. 说明中国抗战具有正义性和世界意义。
3. 中国长期抗战牵制、削弱日本法西斯力量。
4. 中国为世界反法西斯战争胜利作出重大贡献。

## 15. 西安事变的原因和结局

**原因**

1. 日本侵略加剧，民族危机空前严重。
2. 停止内战、一致抗日成为全国人民要求。
3. 中国共产党提出建立抗日民族统一战线。
4. 中国共产党对东北军张学良、西北军杨虎城开展统战工作。
5. 蒋介石仍坚持“攘外必先安内”，逼张、杨继续“剿共”。

**经过与结局**

1. 时间：1936年12月12日。
2. 发动者：张学良、杨虎城。
3. 方式：在西安发动“兵谏”，扣留蒋介石。
4. 主张：提出停止内战、一致抗日等主张。
5. 中共方针：中共中央从民族团结抗日大局出发，派周恩来到西安谈判，坚持和平解决。
6. 结局：蒋介石被迫作出停止“剿共”、联红抗日的承诺。

**意义**

1. 西安事变和平解决成为时局转换的枢纽。
2. 十年内战局面基本结束。
3. 国内和平初步实现。
4. 为第二次国共合作和抗日民族统一战线形成创造重要条件。

## 16. 重庆谈判的原因和内容

**原因**

1. 抗战胜利后，全国人民要求和平、民主、团结，反对内战。
2. 蒋介石一方面积极准备内战，一方面三次电邀毛泽东赴重庆谈判。
3. 蒋介石目的：争取时间、转嫁战争责任、欺骗国内外舆论。
4. 中共目的：争取和平民主，揭露国民党假和平真内战的企图。

**经过与内容**

1. 时间：1945年8月28日，毛泽东偕周恩来、王若飞赴重庆谈判。
2. 文件：1945年10月10日，国共双方签署《政府与中共代表会谈纪要》，即“双十协定”。
3. 基本方针：确认和平建国的基本方针。
4. 合作要求：同意长期合作、坚决避免内战。
5. 政治安排：提出召开政治协商会议等安排。

**意义**

1. 表明中国共产党争取和平民主的诚意。
2. 扩大了中国共产党的政治影响。
3. 使国民党发动内战的真实面目逐步暴露。

## 17. 三大战役

**名称**

1. 辽沈战役。
2. 淮海战役。
3. 平津战役。

**背景**

1. 1948年秋，人民解放战争进入战略决战阶段。
2. 解放区土地改革基本完成，人民群众积极支援前线。
3. 人民解放军力量壮大。
4. 国民党军队士气低落、统治孤立。
5. 战略决战时机成熟。

**经过**

1. 辽沈战役：1948年9月12日至11月2日，东北野战军主力在林彪、罗荣桓领导下歼敌47.2万人，解放东北全境。
2. 淮海战役：1948年11月6日至1949年1月10日，华东野战军、中原野战军等在刘伯承、陈毅、邓小平、粟裕、谭震林组成的总前委领导下歼敌55.5万人。
3. 平津战役：1948年11月29日至1949年1月31日，东北野战军和华北解放军在林彪、罗荣桓、聂荣臻组成的总前委领导下，歼灭和改编国民党军52万余人，北平和平解放。

**意义**

1. 三大战役历时4个月零19天。
2. 共歼灭国民党军154万余人。
3. 基本摧毁国民党赖以维持反动统治的主要军事力量。
4. 是人民战争和毛泽东军事思想的伟大胜利。

## 18. 新中国前几十年建设与“一五计划”

**建设背景**

1. 新中国成立后，国家面临恢复经济、巩固政权的任务。
2. 国家需要实现工业化和社会主义改造。
3. 旧中国工业基础薄弱，尤其重工业落后。
4. 国际环境严峻，西方封锁。
5. 苏联等社会主义国家提供援助。

**“一五计划”时间**

1. 从1953年开始实施。
2. 1955年由一届全国人大二次会议通过。

**主要内容与措施**

1. 集中主要力量发展重工业。
2. 建立国家工业化和国防现代化的初步基础。
3. 相应发展交通运输业、轻工业、农业和商业。
4. 培养建设人才。
5. 保证社会主义成分比重稳步增长。
6. 在发展生产基础上逐步提高人民物质文化生活水平。
7. 以苏联援建的156项工程为中心，建设鞍钢大型轧钢厂、无缝钢管厂、七号炼铁炉等一批重点工程。

**意义**

1. 使我国工业生产能力和技术水平大大提高。
2. 建立一批旧中国没有的基础工业部门。
3. 改善工业布局。
4. 为建立独立完整的工业体系奠定基础。
5. 为社会主义建设积累经验。

## 19. 毛泽东《论十大关系》：背景和主要内容

**写作背景**

1. 1956年前后，我国社会主义改造基本完成。
2. 中国开始探索社会主义建设道路。
3. 苏共二十大后，苏联模式弊端暴露。
4. 中国共产党需要总结我国建设经验，借鉴苏联经验教训。
5. 1955年底到1956年春，毛泽东等中央领导人进行系统调查研究，形成《论十大关系》思路。

**基本方针**

1. 调动党内党外、国内国外一切积极因素。
2. 把我国建设成为强大的社会主义国家。

**主要内容**

1. 重工业和轻工业、农业的关系。
2. 沿海工业和内地工业的关系。
3. 经济建设和国防建设的关系。
4. 国家、生产单位和生产者个人的关系。
5. 中央和地方的关系。
6. 汉族和少数民族的关系。
7. 党和非党的关系。
8. 革命和反革命的关系。
9. 是非关系。
10. 中国和外国的关系。

**意义**

1. 标志中国共产党开始探索适合中国国情的社会主义建设道路。
2. 为中共八大召开作了理论准备。
3. 体现从照搬苏联经验转向独立探索中国道路的努力。

## 20. 改革开放：农村改革、城市改革与南方谈话

### 改革开放的起步

1. 时间：1978年党的十一届三中全会。
2. 重大转折：把党和国家工作中心转移到经济建设上来。
3. 历史决策：作出实行改革开放的历史性决策。
4. 意义：开启改革开放和社会主义现代化建设新时期。

### 1980年代初农村改革

**原因**

1. 人民公社体制下平均主义严重。
2. 农业生产积极性不足。
3. 农村经济困难。
4. 十一届三中全会为改革提供思想前提和政治环境。

**基本内容**

1. 农村改革首先取得突破。
2. 核心是实行以家庭联产承包责任制为主要形式的责任制改革。
3. 前提是坚持土地集体所有。
4. 做法是把土地经营责任承包到户、到组，实行包产到户、包干到户等形式。
5. 农民获得生产经营自主权。
6. 同时改革农产品统购派购制度。
7. 发展乡镇企业和农村商品经济。

**意义**

1. 调动农民积极性。
2. 解放和发展农村生产力。
3. 推动农业增产和农民增收。
4. 为城市改革和整个经济体制改革提供经验。

### 1980年代城市经济体制改革

1. 背景：在借鉴农村改革经验基础上，城市改革逐步展开。
2. 主要内容：扩大企业自主权。
3. 推行经济责任制，把企业和职工利益同经济效益联系起来。
4. 改革商业流通体制。
5. 发展城镇集体经济和个体经济。
6. 逐步形成以公有制为主体、多种经济形式并存的格局。

### 1992年邓小平南方谈话

**背景**

1. 20世纪80年代末90年代初，国际上苏联解体、东欧剧变。
2. 国内改革开放面临困难和思想困惑。
3. 能否坚持党的基本路线、继续推进改革开放成为重大问题。

**主要内容**

1. 改革也是解放生产力。
2. 不改革开放、不发展经济、不改善人民生活只能是死路一条。
3. 判断姓“社”姓“资”，主要看是否有利于发展社会主义社会生产力、增强社会主义国家综合国力、提高人民生活水平。
4. 计划和市场都只是经济手段，不是社会主义和资本主义的本质区别。
5. 社会主义本质是解放生产力、发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。
6. 基本路线要管一百年，动摇不得。
7. 发展才是硬道理。
8. 科学技术是第一生产力。
9. 两手抓，两手都要硬，反对腐败。

**意义**

1. 深刻回答长期困扰人们思想的重大问题。
2. 是把改革开放和现代化建设推向新阶段的又一次思想解放宣言。
3. 对党的十四大确立社会主义市场经济体制改革目标具有重要指导意义。

**近代前期主线**

1. 列强侵略加深民族危机。

7. 解放战争胜利。

3. 《论十大关系》探索中国社会主义建设道路。
4. 十一届三中全会开启改革开放。
5. 农村改革突破。
6. 城市改革推进。
7. 南方谈话推动改革开放进入新阶段。
