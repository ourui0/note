LSP 的契约含义
LSP 要求⼦类遵守⽗类的⾏为契约：
契约要素 L SP 要求
前置条件 ⼦类前置条件 ≤ ⽗类（⼦类不能更严格）
后置条件 ⼦类后置条件 ≥ ⽗类（⼦类保证更多）
不变式 ⼦类必须维护⽗类的所有不变式
违反示例（前置条件更严格）
// ⽗类：接受任意正整数
void setAge(int age) { assert age > 0; }
// ⼦类：要求年龄  < 150 （更严格）
void setAge(int age) {
    assert age > 0 && age < 150; // 违反！
}
记忆⼝诀
⼦类前置放宽，后置加强，
不变式维持——这才叫替换。
